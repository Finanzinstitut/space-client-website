Zugang

Diese Seite hat kein eigenes Passwort und könnte auch keins haben — sie ist eine Datei, die jeder herunterladen kann. Was sie schützt, ist GitHub: ohne gültigen Token lehnt GitHub jede Änderung ab, ganz gleich, was hier eingetippt wird.

  1. Auf GitHub einen fine-grained token anlegen: Einstellungen → Developer settings → Fine-grained tokens
  2. Repository access: nur Finanzinstitut/Space-Client-Mod
  3. Permissions → Contents: Read and write. Sonst nichts.
  4. Expiration: ein Datum setzen. Ein Token, der nie abläuft, ist einer, den man nie zurücknimmt.
